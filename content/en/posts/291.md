**<u>ICFPC 2026. Writeup.</u>**

It was very intense weekend. I burned out all tokens of my brain. Now I want to tell you a little bit about this experience in a futile attempt explaining why it was so much fun.

![Post image](<https://pub-df8eda899f364205ba20a32dc3740d46.r2.dev/telegram/phys_math_dev/b7e3011189a3c838553ca8c924bfac3d9a6316908fd3410d38823b4c4feec76f.jpg>)

The first hour of the contest was, probably the most satisfying one because I read the whole introduction into a crazy graphical programming language in half an hour and solved the first problem just using my brain, without agents and LLMs. You can see that our team has Rank 1 for this solution and it is because of my friend, who extremely optimized my solution.

Let's walk through the solution for this first problem.



![Post image](<https://pub-df8eda899f364205ba20a32dc3740d46.r2.dev/telegram/phys_math_dev/46f80d19c35cba758bb9dee7a6bbc6716a6808b45d42b1874531be12a0f2737c.jpg>)




Through this big gray I number n goes into. Program should calculate n-th triangle number and send it to the big grey O. @ is the initial position of a little man who performs computations. On each tick he moves one step right. According to [the contest textbook](<https://icfpcontest2026.com/textbook>), a man has two arms: A and B. Cell "r" reads the number n and places it into the arm A. Then...

Sorry. Let me remind that nth triangle number is $1 + \cdots + n$ . It would be too long to use loop in order to sum it up, so you can use Gauss' trick: $\frac {n\cdot(n+1)}{2}$

Back to the little man. "M" copies number n to the second arm B. "\*" - no surprise- multiplies two number and places the result to A. "+" sums it up, so we got $n^2+n$. "v" says to man to go down, "\<" - go left. Copy A to B, put 1 to A, swap A and B. "}" - logical shift by 1. So, we divided the number by two, it's our answer. Finally "s" sends it to the output channel.

I hope you got the main idea that in this contest, which was, basically, a leetcode for this language, it was necessary to solve complex problems using this exotic programming language.
