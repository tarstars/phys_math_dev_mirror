# Toward fast Fibonacci. Power

```python
def fast_pow(x, n):
    accum = 1
    p2 = x
    while n:
        if n % 2:
            accum *= p2
        p2 = p2 * p2
        n //= 2

    return accum
```

It's fast exponentiation in Python. If you want, check it [in Rust](<https://github.com/tarstars/leetcode/blob/main/rust/0050/sol_00.rs>). It works because squaring gives us powers of two in x's exponent. On the first iteration $p2 = x^1$, on the second $p2 = x^2$, then $p2 = x^4$, then $p2 = x^8$ etc. Then we use ` accum *= p2 ` in order to collect together powers back to initial value of $n$.
