**<u>ICFPC 2026. Postmortem. Tasks to solve.</u>**

[Previously](<https://t.me/phys_math_dev/291>) I told you how to solve the easiest problem of this contest. Today I want to give you a taste of the whole [problems-set](<https://icfpcontest2026.com/problem-sets>) .

**<u>Triangle</u>**
Sum up all numbers 1 to n. Simple arithmetic.

**<u>Memory</u>**
Implement set(p, v) and get(p) operations

**<u>Reverse a list</u>**
Literally

**<u>Sort</u>**
KO

**<u>History Lesson</u>**
There is a text about previous ICFPCs. You are to write the most compact and effective little man program which reproduces the text. Challenge is in encoding of characters.

**<u>Brackets</u>**
Check whether the brackets sequence is correct

**<u>Packet Reassembly</u>**
There is a stream of (k, v) tuples. Keys are from 1..n range. We are to emit all values v in order of increasing k. Missing number blocks output. Missing output block input.

**<u>Plotter</u>**
Stream of (x1, y1)-(x2, y2) line segments should be plotted on the display

**<u>Grade Book</u>**
Small school-oriented database. We fill down marks for students with different subjects and then run queries like mean mark, best student.

**<u>Matrix Multiply</u>**
KO

**<u>Sudoku Auditor</u>**
If sudoku is correctly solved

**<u>Subset Sum</u>**
Find subset of integers which sums up to the given sum

**<u>Snake</u>**
Emulate snake game

**<u>Pathfinder</u>**
Find the shortest path in a maze and animate it

**<u>LLLM</u>**
Run emulation of little man program, one room

**<u>LLM</u>**
Run emulation of little man program, multiple rooms
