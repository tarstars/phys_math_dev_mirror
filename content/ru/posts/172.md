Простая ферма древесины

Это простая ферма древесины для начала игры.

```python
def best_move(d1, n1, d2, n2):
  d, n  = ((d1, n1), (d2, n2))[n2 < n1]
  for _ in range(n):
    move(d)

def nav(x2, y2):
  x1, y1 = get_pos_x(), get_pos_y()
  n = get_world_size()
  best_move(East, (x2 - x1) % n, West, (x1 - x2) % n)
  best_move(North, (y2 - y1) % n, South, (y1 - y2) % n)

n = 6
set_world_size(n)
while True:
  for y in range(n):
    for x in range(n):
      nav(x, y)
      p = Entities.Tree
      if (x + y) % 2:
        p = Entities.Bush
      if can_harvest():
        harvest()
      plant(p)
```

Разберём несколько интересных моментов.

Прежде всего, мне очень нравится функция `nav`. Она позволяет писать чистый и лаконичный код. Написал один раз — пользуешься всегда. Пока не понадобится серьёзная оптимизация, но это другая история.

```python
n = 6
set_world_size(n)
```

У меня уже довольно развитая ферма. Эти строки уменьшают её до состояния «начало игры». В самом начале лучше использовать:

```python
n = get_world_size()
```

```python
while True:
```

Повторяем сбор урожая.

```python
  for y in range(n):
    for x in range(n):
      nav(x, y)
```

Обходим всё поле.

```python
      p = Entities.Tree
      if (x + y) % 2:
        p = Entities.Bush
```

Шахматный порядок кустов и деревьев позволяет деревьям быстро расти.

```python
      if can_harvest():
        harvest()
```

Довольно важный приём: не даём срубать молодые деревья. Без этого `if` дерево можно срубить, ничего за него не получив.

```python
plant(p)
```

Снова сажаем растение.
