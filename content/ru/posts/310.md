# Почти эффективное вычисление последовательности Фибоначчи

Собеседования при приеме на работу в сфере программирования – это сумасшествие. У моего друга на собеседовании в Meta попросили вывести n-ное число в последовательности Фибоначчи. Мы уже знаем, как этого не делать. Но как это сделать? Мое решение будет следующим:

```python
a, b = 0, 1
for _ in range(n):
    a, b = b, a + b
print(a)
```

Я помню, как сложно мне было решать подобные задачи на Basic, Pascal и C. Там не было такого красивого множественного присваивания. Поэтому мне приходилось манипулировать значениями в нескольких переменных. Это, безусловно, было очень полезно для обучения. Но меня поражает тихая элегантность программы, приведенной выше.

Этот шаблон действительно замечателен. Вы перемещаетесь по последовательности чисел. В любой момент времени переменные 'a' и 'b' содержат последние два числа в последовательности. Вы вычисляете следующее число и сдвигаете эту пару на один шаг вперед. Захватывающе.

Я люблю представлять алгоритм Евклида как "Начните последовательность с двух чисел 'a' и 'b', наибольший общий делитель (НОД) которых вы хотите найти. Затем постройте последовательность, вычисляя остаток от деления двух последних чисел и записывая этот остаток как новый элемент последовательности. Остановитесь, когда достигнете 0. Элемент, предшествующий последнему, является вашим ответом". Использование этого шаблона позволяет вам...

```python

def gcd(a, b):
    while b:
        a, b = b, a%b
    return a
```
