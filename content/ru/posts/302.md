**<u>62. Уникальные пути</u>**

На LeetCode есть задача: посчитать число различных путей на сетке m × n для робота, который может двигаться только вниз или вправо.

Попробуйте догадаться, почему эта программа решает задачу:

```rust
(a, b) = (m - 1, n - 1)
let (n, k) = (a + b, min(a,b));

let mut c = 1;
for q in 0..k {
    c = c * (n - q) / (q + 1);
}
```

Ответ — **c**.
