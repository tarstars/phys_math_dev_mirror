Самый простой алгоритм сортировки кактусов

В последний момент я получил запрос написать самую маленькую программу, которая сортирует кактусы в игре "The Farmer Was Replaced".

Вот моя версия:
```
n = 8
set_world_size(n)

disorder_detected = True
while(disorder_detected):
  disorder_detected = False
  for y in range(n):
    for x in range(n):
      if get_entity_type() != Entities.Cactus:
        if get_ground_type() != Grounds.Soil:
          till()
        if plant(Entities.Cactus):
          disorder_detected = True
      if measure() != None and measure(East) != None and measure() > measure(East):
        if swap(East):
          disorder_detected = True
      if measure() != None and measure(North) != None and measure() > measure(North):
        if swap(North):
          disorder_detected = True
      move(East)
    move(North)
harvest()
```

Разберем это решение:
```
n = 8
set_world_size(n)
```

Здесь я устанавливаю размер мира равным 8 и ввожу новую переменную n для обозначения размера мира.

Рассмотрим интересный прием:

```
disorder_detected = True
while(disorder_detected):
  disorder_detected = False
  ...
  if plant(Entities.Cactus):
          disorder_detected = True
  if swap(East):
          disorder_detected = True
```

Я ввожу флаг disorder_detected и устанавливаю его в True перед началом цикла. Таким образом, цикл будет выполнен хотя бы один раз. Затем, в начале цикла, я сбрасываю этот флаг. Это означает, что если нарушений нет, поле готово к сбору урожая. Нарушениями являются: отсутствие кактусов или кактусы, расположенные не в правильном порядке.

Навигация очень проста. У меня есть два вложенных цикла. Внутренний цикл перемещает дрон горизонтально слева направо. Внешний цикл перемещает его вертикально. Карта имеет форму тора, поэтому дрон появляется слева после пересечения правой границы; аналогично, он появляется внизу после пересечения верхней границы.

```
  if get_entity_type() != Entities.Cactus:
      if get_ground_type() != Grounds.Soil:
        till()
      if plant(Entities.Cactus):
        disorder_detected = True
```
  Когда мы запускаем скрипт, поле пусто. Поэтому мы сажаем кактус на пустую ячейку и считаем это нарушением. Кактусу нужна почва, мы обеспечиваем это с помощью команды till().

И, наконец, самое главное:

```
if measure() != None and measure(East) != None and measure() > measure(East):
  if swap(East):
    disorder_detected = True
if measure() != None and measure(North) != None and measure() > measure(North):
  if swap(North):
    disorder_detected = True
```
  
Если наш текущий кактус выше, чем его сосед справа или сверху, мы меняем их местами. Таким образом, каждый проход дрона приносит больше порядка на поле, и в один прекрасный день поле становится отсортированным. На отсортированном поле не происходит обменов, поэтому нарушения не обнаруживаются, и цикл while завершается.

Дрон останавливается в левом нижнем углу поля, и мы можем вызвать функцию harvest(), которая собирает все кактусы с большим бонусом.
