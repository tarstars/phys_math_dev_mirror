# Умножение матриц для чисел Фибоначчи




![Post image](<https://pub-df8eda899f364205ba20a32dc3740d46.r2.dev/telegram/phys_math_dev/9fd40caed8a29c451a2b02c6b133bc8070375a883aa506c95575bc7ca1071abe.jpg>)

Когда у вас есть четыре каскада RC-фазосдвигающей цепи, написание уравнений Кирхгофа и их решение – довольно рутинная задача. Расчет комплексной передаточной функции по напряжению может легко занять около четырех страниц формата A4. В этой ситуации матричная алгебра может значительно упростить задачу. Ваш вектор $\begin{pmatrix} U_i \\ I_i \end{pmatrix}$ находится на входе цепи, а матрица преобразует его в $\begin{pmatrix} U_o \\ I_o \end{pmatrix}$ на выходе цепи. Это меняет все, потому что вместо набора уравнений вы теперь можете рассуждать об операциях и их свойствах (здравствуйте, теория групп!). Четыре идентичных каскада RC превращаются в матрицу, возведенную в четвертую степень, и, если вы понимаете, что делаете, этот прием упрощает вычисления почти до уровня "просто запишите ответ".

Чтобы использовать эту возможность, нам нужно определить, что представляет собой наш вектор состояния. В электронике это вектор $\begin{pmatrix} U \\ I \end{pmatrix}$; для чисел Фибоначчи это вектор $\begin{pmatrix} a \\ b \end{pmatrix}$, состоящий из двух последовательных чисел. Давайте проверим наше преобразование, которое сдвигает нас на одну позицию вправо:

```python
a, b = b, a + b
```

![Post image](<https://pub-df8eda899f364205ba20a32dc3740d46.r2.dev/telegram/phys_math_dev/993c4a31ddc74120638d4c49655813b5afdfdff4e82e5afc7e5f8c6ecb6ff81e.jpg>)

Теперь можно вывести матрицу для одного шага:

$$
M = \begin{pmatrix} 0 & 1 \\ 1 & 1 \end{pmatrix}.
$$

Теперь идея, которую один из наших подписчиков уже высказал, становится вполне ясной. Возведение матрицы в степень позволяет выполнить необходимое количество шагов.

$$
M^n\begin{pmatrix}0\\1\end{pmatrix} =\begin{pmatrix}F_n\\F_{n+1}\end{pmatrix},
$$

Следовательно, если мы можем быстро вычислять степень матрицы, мы можем быстро вычислить необходимый элемент последовательности Фибоначчи. Нам повезло. Мы только что научились выполнять эту задачу.

```rust
pub fn fib(mut n: i32) -> i32 {
  let (mut xa, mut xb, mut xc, mut xd) = (0, 1, 1, 1);
  let (mut ka, mut kb, mut kc, mut kd) = (0, 1, 1, 1);

  while n > 0 {
    if n % 2 == 1 {
      (xa, xb, xc, xd) = (
        xa * ka + xb * kc,
        xa * kb + xb * kd,
        xc * ka + xd * kc,
        xc * kb + xd * kd,
      );
    }

    (ka, kb, kc, kd) = (
      ka * ka + kb * kc,
      ka * kb + kb * kd,
      kc * ka + kd * kc,
      kc * kb + kd * kd,
    );

    n = n / 2;
  }

  xa
}
```
