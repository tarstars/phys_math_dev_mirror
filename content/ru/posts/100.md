Оператор «морж»

Чтобы завершить предыдущий пост.

```python
n = 0
while (s := input()).lower() != "конец":
    n += 1
print(n)
```

Думаю, это самый элегантный подход. Но здесь используется «оператор морж», который появился только в Python 3.8.
