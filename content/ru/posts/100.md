Оператор «морж»

В завершение предыдущего поста.

```python
n = 0
while (s := input()).lower() != "конец":
    n += 1
print(n)
```
Я думаю, это самый элегантный подход. Но он использует «оператор моржа», который появился только в Python 3.8.
