# Оттенки неэффективности

Худшее, что можно сделать, когда вас просят вычислить биномиальные коэффициенты или числа Фибоначчи, — это написать функцию, которая дословно реализует определение этих объектов, взятое из учебника.

$f(n) = f(n - 1) + f(n - 2), f(1) = 1, f(2) = 1$

$C_n^k = C_{n - 1}^{k - 1} + C_{n - 1}^k, C_n^0 = C_n^n = 1$

Наивный подход выглядит следующим образом:

```python
def c(n, k):
    if n == k or k == 0:
        return 1
    return c(n - 1, k - 1) + c(n - 1, k)

def f(n):
    if n < 3:
        return 1
    return f(n - 1) + f(n - 2)

```

Благодаря красивой симметрии, рекуррентное соотношение для количества вызовов функции почти совпадает с соотношением для самой функции. Это означает, что время выполнения экспоненциально возрастает. Простое решение — использовать кэш или ` lru_cache ` из модуля ` functools `, или хеш-таблицу в других языках:

```python
from functools import cache

@cache
def f(n):
    if n < 3:
        return 1
    return f(n - 1) + f(n - 2)
```

```python
from functools import lru_cache

@lru_cache(maxsize=128)
def f(n):
    ...
```

Таким образом, худшее решение для $C_n^k$ — $T=O(2^n)$. Предположим, что k примерно равно $n/2$. Следующее улучшение, которое можно внести, — рассматривать $C_n^k$ как элемент таблицы (треугольника Паскаля) и строить ее буквально. Это дает $T=O(n^2)$ и $M=O(n^2)$. Это лучше. Еще один трюк — использовать только две строки вместо всей таблицы, что снижает потребление памяти: $M=O(n^2) \rightarrow M=O(n)$. Гимнастика с факториалами, вероятно, даёт лучшее решение: $T=O(n), M=O(1)$.

Мне нравятся такие приемы, как [описанный в предыдущем посте](<https://t.me/phys_math_dev/308>). Мне не нравятся тривиальные вещи, как, например, следить за переполнениями, когда вас просят вычислить $C_{200}^{197}$. В середине этой строки арифметические вычисления могут привести к переполнению с почти $2^{200}$, в то время как вычисление $C_{200}^{197} = C_{200}^3 = \frac {200 \cdot 199 \cdot 198} 6$ вполне осуществимо.

Хорошо, мы знаем решение $T=O(n), M=O(1)$ для $C_n^k$. А как насчет чисел Фибоначчи? В следующий раз.
