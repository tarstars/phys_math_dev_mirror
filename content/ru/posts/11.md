Латекс в Telegram

Я придумал временное решение для публикации текстов с математическими выражениями. Оно не позволяет вставлять формулы в середину строки и довольно громоздко в использовании, но работает. Можно проверить мой текущий подход.

Текущий подход:

𐂅Напишите [статью](<https://github.com/tarstars/telepub/blob/main/article.md>) в markdown
𐂅Используйте [agentic policies](<https://github.com/tarstars/telepub/blob/main/AGENTS.md>) для создания HTML и изображений
𐂅Используйте [редактор шаблона](<https://instantview.telegram.org/my/tarstars.github.io/?url=https%3A%2F%2Ftarstars.github.io%2Ftelepub%2Fgood_looking%2Findex.html>) для генерации IV-ссылки (возможно, ссылка требует моей авторизации)
𐂅Вставьте [ссылку](<https://t.me/share/url?url=https%3A%2F%2Ft.me%2Fiv%3Furl%3Dhttps%253A%252F%252Ftarstars.github.io%252Ftelepub%252Fgood_looking%252Findex.html%26rhash%3D335bb2b74c586e>) в сообщение — появится кнопка Instant View с предпросмотром

Примечания для будущего развития
𐂅улучшить [скрипт сборки](<https://github.com/tarstars/telepub/blob/main/build.mjs>), чтобы сделать преобразование из `.md` в `html + png` более плавным
𐂅выяснить, почему [широкие изображения](<https://tarstars.github.io/telepub/line_math_half/index.html>) не загружаются в Instant View (IV), хотя [узкие](<https://tarstars.github.io/telepub/manual/index.html>) проходят
𐂅придумать решение на основе GitHub Pages, которым можно поделиться: чтобы любой мог клонировать репозиторий и использовать его
𐂅попробовать создать сервис «Telegraph с LaTeX»
