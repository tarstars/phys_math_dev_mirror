Латекс в Telegram

Я придумал временное решение для публикации текстов с математическими выражениями. Оно не позволяет вставлять формулы в середину строки и довольно громоздко в использовании, но работает. Можно проверить мой текущий подход.

Текущий подход:

𐂅Напишите статью в markdown
𐂅Используйте агентские шаги для создания HTML и изображений
𐂅Используйте редактор шаблона для генерации IV-ссылки (возможно, ссылка требует моей авторизации)
𐂅Вставьте ссылку в сообщение — появится кнопка Instant View с предпросмотром

Примечания для будущего развития
𐂅улучшить скрипт сборки, чтобы сделать преобразование из `.md` в `html + png` более плавным
𐂅выяснить, почему широкие изображения не загружаются в Instant View (IV), хотя узкие проходят
𐂅придумать решение на основе GitHub Pages, которым можно поделиться: чтобы любой мог клонировать репозиторий и использовать его
𐂅попробовать создать сервис «Telegraph с LaTeX»
