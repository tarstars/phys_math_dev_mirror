TFWR. Простой сбор урожая тыкв

Цель этого поста — не дать готовый, отполированный и оптимизированный сборщик тыкв для TFWR. Я хочу показать самый простой из известных мне вариантов и пошагово объяснить, как он работает.

```python
def best_move(d1, d2, n1, n2):
  d, n = ((d1, n1), (d2, n2))[n2 < n1]
  for _ in range(n):
    move(d)

def nav(x2, y2):
  x1, y1 = get_pos_x(), get_pos_y()
  n = get_world_size()
  best_move(East, West, (x2 - x1)%n, (x1 - x2)%n)
  best_move(North, South, (y2 - y1)%n, (y1 - y2)%n)
```

Моя любимая навигация. Почему она работает, написано [здесь](<https://t.me/phys_math_dev/59>).

```python
n = 12
set_world_size(n)
```

Для наглядности видео возьмём ферму со стороной 12 клеток. Если эта функция у вас ещё недоступна, размер фермы можно узнать так:

```python
n = get_world_size()
```

Начнём со вспашки всей фермы.

```python
for y in range(n):
  for x in range(n):
    nav(x,y)
    if get_ground_type() == Grounds.Grassland:
      till()
```

Два цикла позволяют посетить каждую клетку фермы. Тип почвы стоит проверять: без проверки скрипт каждый раз будет менять его на противоположный.

Теперь составим план нашей тыквенной затеи.

```python
plan = []
for y in range(n):
  for x in range(n):
    plan.append((x, y))
```

Мы создали список кортежей с координатами всех клеток, в которых хотим получить спелые тыквы.

```python
while plan:
  x, y = plan.pop(0)
  nav(x, y)
  if not can_harvest():
    plant(Entities.Pumpkin)
    plan.append((x, y))
```

```
while plan
```

— довольно интересная конструкция. Она выполняет код, пока в списке `plan` что-нибудь есть. Условие можно записать как `len(plan) > 0`, но `while plan` больше соответствует духу Python.

Затем мы берём пару координат из начала списка и идём в точку (x, y). Здесь начинается самая хитрая, по крайней мере для меня, часть.

Тыква может уже созреть — тогда `can_harvest()` вернёт `True`. Если нет, остаются два варианта: тыква здорова, но ещё растёт, либо она погибла. Этот код изящно обрабатывает все случаи: пытается посадить тыкву. Если она уже растёт, `plant` ничего не делает. Если погибла — заменяет её новой. Во всех этих случаях тыкву стоит проверить ещё раз, поэтому мы добавляем кортеж с координатами в конец списка.

Когда мы вышли из цикла, план пуст. Значит, все тыквы созрели и можно собирать урожай.

И наконец, нужно сделать бесконечный цикл, чтобы продолжать сбор урожая.
