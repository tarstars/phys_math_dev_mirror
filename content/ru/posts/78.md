ТФВР. Координация дронов.

В прошлый раз мы обсуждали, как создавать дронов. Сегодня давайте обсудим, как скоординировать их деятельность.

В игре довольно ограниченное количество трюков, позволяющих координировать дроны. Давайте воспользуемся подходом с «дроном-центральным координатором» и используем количество дронов в качестве инструмента синхронизации.

Я думаю, что одна из самых простых задач — посадить подсолнухи, так что давайте займемся этим. Пул задач — это пул столбцов. Я хочу сохранить работу основного дрона, который мы видим на экране, и попросить его распределить задачи среди других дронов. Давайте обсудим основные моменты этого подхода.

Давайте проверим функцию spawn_drone. В качестве параметра он принимает функцию, которая управляет новым дроном. У меня 32 дрона и 32 колонны. Поэтому необходимо создать инструмент для создания этих параметризованных функций дронов. Давайте сделаем это с помощью подхода «фабричной функции». Он принимает номер столбца в качестве параметра и возвращает функцию дрона с правильной параметризацией.

```python
def f(column):
  def g():
    one_drone_plant_job(column)
  return g
```

Простая функция для посадки всех подсолнухов в заданном столбце:

```python
def one_drone_plant_job(column):
  n = get_world_size()
  for y in range(n):
    nav(column, y)
    if can_harvest():
      harvest()
    if get_ground_type() == Grounds.GrassLand:
      till()
    plant(Entities.Sunflower)
```

И, наконец, код для менеджера

Давайте составим список задач

```python
tasks = []
for t in range(get_world_size()):
  tasks.append(t)
```

Рассылайте их между дронами

```python
while True:
  tasks = []
  for t in range(get_world_size()):
    tasks.append(t)

  while tasks:
    t = tasks.pop()
    while num_drones() == 16: # max_drones():
      pass
    spawn_drone(f(t))
```

Этот цикл «прохода» представляет собой инструмент «межпроцессной синхронизации», который использует количество дронов в качестве объекта синхронизации. Когда цикл «пока задачи» завершается, работа завершена — поле полно подсолнухов.
