# К быстрому вычислению чисел Фибоначчи. Возведение в степень.

```python
def fast_pow(x, n):
    accum = 1
    p2 = x
    while n:
        if n % 2:
            accum *= p2
        p2 = p2 * p2
        n //= 2

    return accum
```

Это быстрое возведение в степень на Python. Если хотите, можете посмотреть реализацию [на Rust](<https://github.com/tarstars/leetcode/blob/main/rust/0050/sol_00.rs>). Это работает, потому что возведение в квадрат позволяет нам получать степени двойки в показателе степени x. На первой итерации $p2 = x^1$, на второй $p2 = x^2$, затем $p2 = x^4$, затем $p2 = x^8$ и так далее. Затем мы используем ` accum *= p2 `, чтобы перемножить нужные степени x и получить $x^n$ для исходного значения $n$. В коде на GitHub есть некоторые скучные детали, которые вам следует помнить на собеседовании. Отрицательные показатели, x, равный нулю, и так далее. Я ненавижу это.
